# 03 — קטלוג הספרים וחיפוש

הספרנית רוצה למצוא ספר במהירות ולדעת אם יש עותק פנוי. בוני את מסך הקטלוג ואת שאילתות החיפוש.

## מה רואים ב־UI?
- חיפוש בשם ספר או בברקוד; מסנן גיל ומתג זמינים בלבד.
- כרטיסים או טבלה: שם, גיל, מספר עותקים וזמינים; לחיצה פותחת כרטיס ספר.
- קישורים לקליטה ידנית, ייבוא ספרים ועמדת הסריקה; מצב ריק והודעת שגיאה.

## חוזה HTTP
בשרת הנתיב ללא /api; בדפדפן מוסיפים /api.

| Method | Path | Request | Response |
|---|---|---|---|
| GET | `/books?q=&ageGroup=&availableOnly=false` | `פרמטרי חיפוש מקודדים ב־URL` | `{ items: CatalogItem[] }` |
| GET | `/copies?bookId=` | `bookId אופציונלי` | `{ items: CopyView[] }` |

## כללי המימוש
- עותק זמין כשאין לו השאלה עם returnedOn=null. אין עמודת סטטוס נפרדת.
- ספר עם כמה עותקים מופיע פעם אחת. ספירת עותקים לא תתנפח עקב JOIN עם היסטוריית השאלות.
- חיפוש ברקוד מדויק או שם חלקי. סדר יציב לפי שם ומזהה. פרמטרים ב־SQL מוכנסים רק באמצעות placeholders.
- טעינה מחדש לאחר חזרה למסך; לא לשמור תוצאות כמקור אמת ב־localStorage.

## בדיקות קבלה — חובה
- מסע אל האי הנעלם מוצג עם 2 עותקים, אחד זמין.
- חיפוש LIB-000002 מוצא את אותו ספר.
- זמינים בלבד מסתיר את הסוד שבין המדפים.
- ספר שלא נמצא מציג מצב ריק; בקשת שרת שנכשלה אינה הופכת לרשימה ריקה.

## תלויות וחיבור
אפשר לפתח ישירות מול מסד הדוגמה בלי לחכות למשימה אחרת.

GET /books ו־GET /copies, בשימוש משימות 02, 05 ו־10.

## הגשה

2. אם נוצר מודול שרת חדש, הפעילי מחדש npm run dev.
