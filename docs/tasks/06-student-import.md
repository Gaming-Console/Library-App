## מה רואים ב־UI?
- בחירת xlsx וקישור להורדת תבנית.
- תצוגת שורות עם סימון חדש, עדכון או שגיאה; סיכום כמויות.
- אישור פעיל רק כשכל השורות תקינות; לאחר הייבוא הצגת added ו־updated.

## חוזה HTTP
בשרת הנתיב ללא /api; בדפדפן מוסיפים /api.

| Method | Path | Request | Response |
|---|---|---|---|
| POST | `/imports/students` | `{ rows: StudentInput[] }` | `{ added: number, updated: number }` |

## כללי המימוש
- read-excel-file/browser בצד הלקוח; שורת כותרות קבועה: מזהה תלמידה | שם מלא | כיתה.
- מזהה צריך להישמר כטקסט, כדי לא לאבד אפסים מובילים. עד 1000 תלמידות ובקשה עד 5MB.
- דחי מזהה כפול בקובץ ושדות ריקים. השרת מאמת מחדש את הנתונים.
- בשרת: transaction שעוטף קריאות saveStudent לכל שורה. אם schoolId כבר קיים, העבירי את ה־id הקיים לעדכון. תלמידות שלא בקובץ אינן נמחקות.

## בדיקות קבלה — חובה
- קובץ עם S001 קיים ו־S004 חדש מחזיר added=1, updated=1.
- ייבוא חוזר אינו יוצר כפילויות.
- מזהה כפול בקובץ או שורה חסרה מונעים ייבוא, כולל בשרת.
- עדכון שם לא מוחק היסטוריית השאלות.

## תלויות וחיבור

רשימת תלמידות ליתר המערכת.

## הגשה
1. פתחי `http://127.0.0.1:5173/#/06-student-import`.

4. צרפי ל־PR צילום מסך, הוראות בדיקה ותלויות שטרם מוזגו.
5. הוסיפי רק את קובצי המשימה, commit ו־push לענף שלך. לא ל־main.
