בוני מסך שבו בוחרים עותקים ומציגים ברקודים אמיתיים, שאפשר לסרוק מהמסך ולהוריד לקובץ.

אין קבצים מוכנים עבורך בתיקייה זו. את וה־AI יוצרים אותם. לא משנים קבצים משותפים או קבצים של משתתפת אחרת.

## מה רואים ב־UI?
- בחירת ספר ועותקים עם תיבות סימון.
- מדבקה: שם ספר, גיל יעד, CODE128 והמזהה בטקסט קריא.
- מצב הגדלה לסריקה וכפתור הורדת HTML עצמאי עם SVG מוטמע.

## חוזה HTTP
בשרת הנתיב ללא /api; בדפדפן מוסיפים /api.

| Method | Path | Request | Response |
|---|---|---|---|
| GET | `/copies?bookId=` | `מסופק על ידי משימה 03` | `{ items: CopyView[] }` |

## כללי המימוש
- JsBarcode בפורמט CODE128, רקע לבן וקווים שחורים; להשאיר שוליים סביב הקוד.
- טקסט ספרים חייב לעבור escaping ביצירת HTML. לא להזריק שם ספר גולמי ל־innerHTML.
- הקובץ המורד מכיל SVG ולא תלוי באינטרנט או בשרת. אין חובת מדפסת בסדנה.
- אם /copies טרם מוזג, השתמשי ב־fixture לבדיקות בלבד; במסך עצמו 404 מוצג כתלות שעדיין לא מומשה.

## בדיקות קבלה — חובה
- ל־LIB-000001 מוצג SVG אמיתי שמכיל קוד תואם, לא קווים דקורטיביים.
- הורדת קובץ נפתחת גם ללא רשת עם כל המדבקות שנבחרו.
- הצגה חוזרת של מדבקות אינה משנה אף נתון במאגר.
- נסי לסרוק מהמסך בסורק שנבדק מראש; אם אינו מתאים, אמתִי גם בהקלדת הקוד.

## הגשה
1. פתחי `http://127.0.0.1:5173/#/05-labels`.
2. אם נוצר מודול שרת חדש, הפעילי מחדש npm run dev.
3. הריצי `npm test`, `npm run build` ו־`npm run check:scope -- 05-labels`.
4. צרפי ל־PR צילום מסך, הוראות בדיקה ותלויות שטרם מוזגו.
5. הוסיפי רק את קובצי המשימה, commit ו־push לענף שלך. לא ל־main.
