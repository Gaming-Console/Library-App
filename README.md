# מדף — ספריית בית הספר

מערכת לניהול ספרייה בית־ספרית: השאלה והחזרה בסריקה, קטלוג, תלמידות, מעקב איחורים וגיבוי. פועלת במחשב אחד, בלי ענן ובלי חשבון.

## הפעלה בלחיצה אחת

דרוש Node.js 20.19 ומעלה ([הורדה](https://nodejs.org)).

- **Windows:** לחיצה כפולה על `start.bat`
- **Mac / Linux:** `./start.sh`

בהפעלה הראשונה המערכת מתקינה ובונה בעצמה (כדקה). הדפדפן נפתח לבד על http://127.0.0.1:3001. אם השרת נופל, הוא עולה מחדש אוטומטית. לסיום סוגרים את החלון.

לנסות עם נתונים פיקטיביים (רק כשעדיין אין מסד): `npm run app -- --demo`.

## מה בתפריט

ארבעה חלקים ועוד הגדרות; כל השאר לשוניות בתוך החלק:

| חלק | לשוניות |
|---|---|
| סריקה | השאלה והחזרה |
| ספרים | קטלוג · הוספת ספר · ייבוא מאקסל · מדבקות |
| תלמידות | רשימה · ייבוא מאקסל |
| השאלות | מעקב ותאריכי החזרה |
| הגדרות | מדיניות השאלה · גיבוי ושחזור |

## סיור הדרכה

בכניסה הראשונה נפתח סיור קצר שמראה איפה כל דבר ואיך מתחילים (ייבוא תלמידות, ספרים, מדבקות, סריקה). אפשר לחזור אליו בכל רגע מהכפתור "הדרכה" בתחתית התפריט.

## לוגו וצבעים

הלוגו נמצא ב־`public/logo.png` (רקע שקוף); כדי להחליף אותו מחליפים את הקובץ. הצבעים מוגדרים במשתנים ב־`src/shell.css`.

## נגישות ונוחות

דילוג לתוכן, ניווט מקלדת עם מיקוד גלוי, קורא מסך (ARIA, הודעות מצב ושגיאה), כיבוד `prefers-reduced-motion`, כפתור "תצוגה גדולה" שנשמר בדפדפן, והדפסת מדבקות בלי תפריטים.

## הגנה על המידע

- השרת מאזין ל־127.0.0.1 בלבד, ודוחה כתובת (Host) ומקור (Origin) זרים.
- כותרות אבטחה (CSP, מניעת framing ו־sniffing) ובקשות שינוי רק כ־JSON.
- גיבוי יומי אוטומטי של המסד ל־`data/backups` (14 האחרונים), ובנוסף גיבוי ושחזור ידניים במסך ההגדרות.
- אין לשים מידע אמיתי של תלמידות לפני אישור בית הספר, בדיקת פרטיות ושחזור.

## פיתוח

```powershell
npm ci
npm run data:demo
npm run dev      # http://127.0.0.1:5173
npm test
npm run build
```

מסד הנתונים: `data/library.sqlite` (מחוץ לגיט). תהליך שרת אחד בלבד מול קובץ מסד. מסמכי העיצוב והחוזים נמצאים ב־`docs/`.
