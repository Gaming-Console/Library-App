# מדף — ערכת סדנת פיתוח ספרייה עם AI

**זהו אתר התחלתי ריק, לא מערכת ספרייה ממומשת.** 12 המשתתפות בונות פיצ׳רים עם UI ושרת. השאלה והחזרה הן משימה אחת בעמדת סריקה אחת.

## התחלה מהירה

Node.js 20.19+ או 22 LTS:

```powershell
npm ci
npm run data:demo
npm run dev
```

`data:demo` מריצים פעם אחת בלבד; היא מסרבת להחליף נתונים קיימים. אם הפורטים 5173 או 3001 תפוסים, יש לעצור רק את התהליך הידוע שמשתמש בהם, לא תהליכים לפי שם.

- האתר הריק: http://127.0.0.1:5173
- כרטיסים והנחיות: http://127.0.0.1:5173/workshop/index.html
- הדמיות לצילום: http://127.0.0.1:5173/workshop/mockups.html
- בדיקת שרת: http://127.0.0.1:5173/api/health

אפשר גם לפתוח את public/workshop/index.html ואת mockups.html ישירות בדפדפן; הקוד והדוגמאות מוטמעים מקומית. קישורי אפליקציה דורשים שרת פיתוח.

## מה מקבלים בקוד?

- React + TypeScript + Vite עם עמוד התחלה אחד.
- Express שמגלה מודולי Router עתידיים, בדיקת תקינות וחיבור SQLite.
- טיפוסי ישויות משותפים.
- מבנה SQL ונתונים פיקטיביים להכנת מסד הפיתוח.
- קובצי תלויות ונעילה; node_modules ונתוני SQLite אינם נכללים בגיט.
- אין מסכי ספרייה, פעולות עסקיות או תיקיות מוכנות לכל משתתפת.

## בדיקות

```powershell
npm test
npm run build
npm run check:kit
```

אלה בדיקות התשתית והחומרים בלבד, לא הוכחה למוצר מוגמר. אחרי מימוש נדרשות בדיקות המשתתפות ומסלול הקבלה במדריך.

## שימוש מקומי לאחר השלמת הפיתוח

`npm run build` ואז `npm start`. פותחים http://127.0.0.1:3001. מסד הנתונים הוא data/library.sqlite; אין ענן ואין סנכרון. אין לשים בו מידע אמיתי לפני בדיקת פרטיות, גיבוי ושחזור ואישור בית הספר. אין פריסה מרוחקת או מאגר Git שנוצרו אוטומטית.
