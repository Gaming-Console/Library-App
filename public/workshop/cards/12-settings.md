## מה רואים ב־UI?
- טופס שם הספרייה, מספר ימי השאלה ומגבלת ספרים פעילים לתלמידה.
- תצוגה מקדימה: אם משאילים היום, מתי צריך להחזיר לפי הערך שבטופס.
- שמירה, ביטול שינויים, הודעת הצלחה ושגיאות שדה.

## חוזה HTTP
בשרת הנתיב ללא /api; בדפדפן מוסיפים /api.

| Method | Path | Request | Response |
|---|---|---|---|
| GET | `/settings` | `ללא גוף` | `Settings` |
| PUT | `/settings` | `Settings` | `Settings` |

## כללי המימוש
- loanDays מספר שלם 1–90; maxActiveLoans מספר שלם 1–20; שם לא ריק. האימות גם בשרת.
- קיימת שורת settings אחת עם id=1. אין יצירת שורה נוספת בכל שמירה.
- תצוגה מקדימה מחשבת ימי לוח ומסתדרת במעבר חודש ושנה.
- שמירה לא משנה dueOn של השאלות קיימות; ביטול מחזיר את הערכים האחרונים מהשרת.

## בדיקות קבלה — חובה
- ערכים נשמרים ונטענים מחדש אחרי רענון.
- 0, 1.5 ו־91 ימי השאלה נדחים.
- ביטול שינויים מחזיר את הטופס למצב השמור.
- משימה 09 משתמשת בערך החדש בהשאלה הבאה, וההשאלה הישנה לא משתנה.

## הגשה
1. פתחי `http://127.0.0.1:5173/#/12-settings`.
2. אם נוצר מודול שרת חדש, הפעילי מחדש npm run dev.
3. הריצי `npm test`, `npm run build` ו־`npm run check:scope -- 12-settings`.
4. צרפי ל־PR צילום מסך, הוראות בדיקה ותלויות שטרם מוזגו.
5. הוסיפי רק את קובצי המשימה, commit ו־push לענף שלך. לא ל־main.
